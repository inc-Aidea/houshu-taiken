# 報酬デスク 体験版

軽貨物の会社が、元請から届く支払明細をもとに、委託ドライバーの月の報酬を計算する仕組みの体験版です。X で紹介していただく方に、実際に触って・撮っていただくためのものです。用意した画面を順番に切り替えて見せるもので、計算の仕組みは入っていません。

## 開き方

1. 緑の「Code」→「Download ZIP」で落として、解凍します。
2. `docs` フォルダの `index.html` を、Chrome で開きます（ダブルクリックで動きます）。

インストール・ログイン・サーバーは要りません。入力した内容はそのパソコンのブラウザの中だけに残り、外には送られません。右上の「最初に戻す」で何度でもやり直せます。

| ファイル | 画面 |
|---|---|
| `docs/index.html` | 事務所の画面（毎月の締め・台帳・振込・損益） |
| `docs/driver.html` | ドライバーのスマホの画面 |
| `docs/guide.html` | 触り方 |
| `images/` | 投稿に使える画面の画像 |

## 5分で見せる順番

1. 「9月分の締め」で、元請4社の「見本を入れる」を押す。
2. 明細と本人の報告の食い違いが5件出る。「明細どおり」などを選ぶ（台帳にない人は「報酬の対象外」）。
3. 車両代・立替・前払いが自動で引かれていることを見せる。
4. 報酬がマイナスの人を「請求書にする」。
5. 確定して、支払明細を開く。外注の会社あての1枚も出る。
6. 「ドライバー画面を見る」で、スマホ側を見せる。

## 紹介するときのお願い

**書いてよいこと**

- 元請ごとに形の違う支払明細（PDF・写真・Excel）を AI が読み取り、報酬の計算・支払明細・振込一覧まで1つの画面で終わる（読み取りは導入版の機能。体験版は見本だけ）
- 明細とドライバー本人の報告の食い違いを見つける
- ドライバーは公式LINE から稼働報告・前払いの申し込み・支払明細の確認ができる（導入版）
- 計算は決まった規則で行い、AI は明細の読み取りにだけ使う

**書かないでいただきたいこと**

- 導入している会社の名前、導入社数
- 「○時間削減」「ミスがゼロになる」など、根拠を示せない数字や断定
- 料金（お問い合わせで案内します）
- 体験版の画面を、実在の会社の画面として見せること

**表記**

- 依頼を受けた投稿だと分かるように、投稿の見えやすい位置に「PR」または「広告」と書いてください（景品表示法のステルスマーケティング規制への対応）。
- 会社名は「株式会社Aidea」、読みは「アイディア」です。相談先は https://inc-aidea.com/ です。
