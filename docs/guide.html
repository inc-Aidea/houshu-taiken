報酬デスク 体験版の触り方

画面に戻る

軽貨物の会社が、元請から届く支払明細をもとに、委託ドライバーの月の報酬を計算する仕組みです。9月分の締めを、最初から最後まで試せます（5分ほど）。

触る順番

  1. 明細を入れる：「9月分の締め」で、元請4社の「見本を入れる」を押します。
  2. 食い違いを片づける：明細とドライバー本人の報告が合わないところが5件出ます。「明細どおり」（台帳にない人は「報酬の対象外」）を押します。
  3. 差し引きを見る：車両代・立替・前払いは自動で引かれます。紹介料のように上乗せして払うものも入っています。
  4. マイナスの人を決める：小林 誠さんは修理代が報酬を上回ります。「翌月に繰り越す」か「請求書にする」を押します。
  5. 確定する：支払明細と振込一覧が出ます。外注の会社に属する2人は、会社あてに1枚にまとまります。
  6. ドライバーの画面を見る：右上の「ドライバー画面を見る」で、稼働報告・前払いの申し込み・支払明細を試せます。
  7. 損益を見る：「損益」で、月ごとの粗利が出ます。

2026年8月分（確定済み）も、上の月の欄から見られます。何度でもやり直せます。右上の「最初に戻す」を押してください。

体験版と、実際の導入版の違い

明細の読み取り体験版は、用意した見本4社だけです。導入版は、届いた PDF・写真・Excel を AI が読み取ります。
ドライバーの操作体験版は、この画面の中だけです（人や個数は固定）。導入版は、公式LINE のメニューから開き、お知らせも LINE に届きます。
動く操作体験版は、上の順番で使う操作だけが動きます。ほかのボタンを押すと、その旨が出ます。
データ体験版は、お使いのブラウザの中だけに残ります。外には送りません。会社・人・金額・口座はすべて架空です。
